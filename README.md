# TechPulse Newsletter
 CrewAI with a Researcher that can search the web using SerperDevTool and a Writer that cannot search at all. The Researcher finds today's top 3 tech news stories; the Writer turns them into a 5-line newsletter. The tasks run sequentially, and the second only works if you hand it the first's output. Tools: Python, CrewAI, crewai-tools, Serper and OpenAI API keys
